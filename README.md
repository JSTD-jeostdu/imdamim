# IM-DAM-IM · 아임담임

담임 교사를 위한 학급 운영 도우미. 설치·가입 없이 웹 주소만으로 시작합니다.

- 바로 쓰기: https://jstd-jeostdu.github.io/imdamim/
- 심사·체험용 바로가기: https://jstd-jeostdu.github.io/imdamim/?demo=1
- 권장 브라우저: 네이버 웨일 (크롬·엣지·사파리에서도 동작)

## 실행 방법

1. **배포 주소로 열기 (권장)** — 위 체험용 주소를 열면 로그인 없이 가상 학급(학생 25명)으로 바로 들어갑니다.
2. **ZIP으로 열기** — 압축을 풀고 `index.html`을 더블클릭합니다. 소개 화면에서 「가상 학급으로 둘러보기」를 누르세요.
   - 글꼴·QR·엑셀 읽기 부품을 인터넷에서 불러오므로 **인터넷 연결이 필요**합니다.

## 로그인 여부

- 체험 모드는 **로그인이 필요 없고, 서버에 아무것도 저장하지 않습니다.** 새로 고치면 처음 상태로 돌아갑니다(「체험 초기화」 단추도 있음).
- 실제 사용 방식은 세 가지 중 고릅니다.
  - 학교 승인 후 동기화 — 구글 로그인, 여러 기기·교과 출석부·학생 소통 기능
  - 내 기기에서만 — 로그인 없음, 서버 전송 없음
  - 번호만 사용 — 로그인 없음, 이름 미수집
- 학생·교과 선생님은 로그인하지 않습니다(학생은 개인 코드, 교과 선생님은 출석부 암호).

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 앱 전체 (단일 파일) |

| `favicon.*`, `apple-touch-icon.png`, `og-image.png` | 아이콘·공유 이미지 |
